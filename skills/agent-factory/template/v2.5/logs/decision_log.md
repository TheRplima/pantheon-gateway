# Decision Log

> [!NOTE]
> This file records significant decisions with their reasoning.
> Use this for auditability and learning from past choices.

## Format

```
### [YYYY-MM-DD HH:MM] Decision Title
**Context:** What led to this decision
**Options Considered:** List of alternatives
**Decision:** What was chosen
**Reasoning:** Why this option was selected
**Outcome:** (fill in later) What happened as a result
```
